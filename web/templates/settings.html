Command line

The same binary is the CLI. Point it at this dashboard with the API token:

export SIGNPOST_URL=https://{{or $v.AdminHost "links.example.com"}} SIGNPOST_TOKEN=…
signpost add milind.dev/ade https://example.com -note "ADE"
signpost import links.csv -dry-run
signpost export > links.csv
