{{icon "info" "icon-sm text-fg-3"}}How the DNS check works

signpost reads the records from 1.1.1.1, then proves the round trip by fetching a secret token from https://host/.well-known/signpost/. Proxied Cloudflare records never show this box's IP, so the fetch is the real proof. Checks run again every 6 hours.

{{icon "triangle-alert" "icon-sm text-fg-3"}}Fallbacks take over the whole host

A fallback sends every path without a link to a URL, e.g. https://www.example.com/{path}. Only set one on hosts where nothing else is served.
